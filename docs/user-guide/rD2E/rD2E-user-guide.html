rD2E user guide

rD2E connects R code in the D2E notebook to D2E. With it you can load cohort definitions from ATLAS, create new ones, and submit a Strategus analysis specification to run on a D2E dataset.

Where it works

  • In R cells of the D2E notebook (ATLAS → Studies → open or create a notebook).
  • It is loaded for you. You don't need to install anything. library(rD2E) is accepted but not required.
  • R's built-in help (?get_cohort_definition_set) is not available for rD2E. This guide is the reference.

The four functions

Function What it does
get_cohort_definition_set() Load cohort definitions from ATLAS by ID
create_cohort_definition() Create a new cohort definition in ATLAS
create_options() Choose the dataset and result settings for a run
run_strategus_flow() Submit an analysis specification to D2E

How they fit together

ATLAS cohort IDs
   → get_cohort_definition_set()      load the cohorts
   → build the analysis specification  (Strategus functions)
   → create_options()                  pick the dataset, name the results
   → run_strategus_flow()              submit; returns a flow run ID

Getting started

This walkthrough follows an example study: the incidence of postpartum type 2 diabetes in pregnancies with and without gestational diabetes (GDM). Replace the cohort IDs, dataset code and results name with your own.

1. Find your cohort IDs

In ATLAS, open Cohort Definitions. The ID column is the number you use in R. This example uses:

ID Cohort
44 GDM Cohort
49 Non-GDM Cohort
50 Postpartum T2D Outcome Cohort

2. Load the cohorts

library(Strategus)
library(CohortIncidence)

cohortDefinitionSet <- get_cohort_definition_set(
  cohortIds = c(44, 49, 50),
  generateStats = TRUE
)

The notebook prints one line per cohort (in red; these are progress messages, not errors):

Fetching cohortId: 44
Fetching cohortId: 49
Fetching cohortId: 50

Check what you loaded:

print(cohortDefinitionSet[, c("cohortId", "cohortName", "generateStats")])

  cohortId                    cohortName generateStats
1       44                    GDM Cohort          TRUE
2       49                Non-GDM Cohort          TRUE
3       50 Postpartum T2D Outcome Cohort          TRUE

3. Build the analysis specification

Building the specification uses Strategus functions, not rD2E. See the Strategus documentation for the modules and their settings. In this study:

# The analysis: incidence of cohort 50 in cohorts 44 and 49 (irDesign is defined in an earlier cell)
ciModule <- Strategus::CohortIncidenceModule$new()
ciSpecs  <- ciModule$createModuleSpecifications(irDesign = irDesign)

# The cohorts, shared by every module, and the step that generates them
cohortResources <- createCohortSharedResourceSpecifications(
  cohortDefinitionSet = cohortDefinitionSet)
cgSpecs <- createCohortGeneratorModuleSpecifications(generateStats = TRUE)

# Put it together: cohorts first, then Cohort Generator, then the analysis
analysisSpecifications <- createEmptyAnalysisSpecifications()
analysisSpecifications$sharedResources <- list(cohortResources)
analysisSpecifications <- addModuleSpecifications(analysisSpecifications, cgSpecs)
analysisSpecifications <- addModuleSpecifications(analysisSpecifications, ciSpecs)

4. Choose the run options

options <- create_options(
  source_token_study_code = "my_dataset",
  analysis_results_name   = "t2d_incidence_v1"
)
options[c("datasetId", "analysisResultsName")]

$datasetId
[1] "my_dataset"
$analysisResultsName
[1] "t2d_incidence_v1"

5. Submit

Run this once. Every run of this cell submits a new study run.

result <- run_strategus_flow(
  analysisSpecification = analysisSpecifications,
  executionSettings     = NULL,
  options               = options
)

Strategus flow run triggered successfully with id: 923fb707-c76f-45cd-ba05-4a8c8d03a214

print(result)

$flowrunId
[1] "923fb707-c76f-45cd-ba05-4a8c8d03a214"
$status
[1] "Successfully created a flow run"

The flow run ID means D2E accepted the run. It does not mean the analysis has finished. See Submitting a study for what happens next.

Function reference

get_cohort_definition_set()

Load cohort definitions from ATLAS into R, ready to use in a Strategus analysis specification.

Usage

get_cohort_definition_set(cohortIds, generateStats = FALSE)

Arguments

Argument Type Default Meaning
cohortIds numeric vector required ATLAS cohort definition IDs (the ID column in ATLAS → Cohort Definitions). At least one.
generateStats TRUE / FALSE FALSE Stored in the generateStats column of every row. Set it to match the generateStats you give the Cohort Generator module.

Value

A data frame with one row per cohort, in the order you asked for them:

Column Contents
atlasId The ATLAS ID
cohortId The same ID; this is the one Strategus uses
cohortName The name in ATLAS
sql Always empty in the notebook
json The cohort definition, as JSON text
logicDescription The description in ATLAS, or NA if there is none
generateStats The value you passed 
print(cohortDefinitionSet[, c("cohortId", "cohortName", "generateStats")])

  cohortId                    cohortName generateStats
1       44                    GDM Cohort          TRUE
2       49                Non-GDM Cohort          TRUE
3       50 Postpartum T2D Outcome Cohort          TRUE

Examples

# Load three cohorts and keep inclusion statistics
cohortDefinitionSet <- get_cohort_definition_set(
  cohortIds = c(44, 49, 50),
  generateStats = TRUE
)

# Check you got what you expected before building the specification
stopifnot(identical(as.integer(cohortDefinitionSet$cohortId), c(44L, 49L, 50L)))
print(cohortDefinitionSet[, c("cohortId", "cohortName")])

Function reference

create_cohort_definition()

Create a new cohort definition in ATLAS from R.

Usage

create_cohort_definition(name, description, cohort_definition)

Arguments

Argument Type Default Meaning
name text required Name of the new cohort. Must not be empty.
description text required Description of the new cohort. Must not be empty.
cohort_definition list or JSON text required The cohort definition. Either the definition itself, or an ATLAS export that has an expression field (and optionally expressionType).

If expressionType is not given, SIMPLE_EXPRESSION is used.

Value

The new cohort definition as stored in ATLAS, as a list. Its id is the new cohort ID to use in get_cohort_definition_set(). TO VERIFY the other fields returned.

The new cohort is tagged created_by_rD2E, so you can find it in ATLAS → Cohort Definitions.

Examples

Copy an existing cohort under a new name:

existing <- get_cohort_definition_set(50)

newCohort <- create_cohort_definition(
  name              = "Postpartum T2D (copy for sensitivity analysis)",
  description       = "Copy of cohort 50, created from the notebook",
  cohort_definition = existing$json[1]
)

newCohort$id   # the new cohort's ID

Running this creates a real cohort definition in ATLAS. TO VERIFY

Function reference

create_options()

Choose which dataset a study runs on and how its results are named, before you submit it with run_strategus_flow().

Usage

create_options(source_token_study_code, analysis_results_name = NULL)

Arguments

Argument Type Default Meaning
source_token_study_code text the current session's dataset The code of the dataset to run on, for example "my_dataset". TO VERIFY which dataset is used when you leave it out, and where researchers find a dataset's code.
analysis_results_name text none A name for this set of results, for example "t2d_incidence_v1". One string, at most 255 characters, no control characters. Spaces at either end are removed; an empty name is ignored.

Value

A list of run options to pass as options to run_strategus_flow(). Nothing is sent to D2E by this function.

options <- create_options(
  source_token_study_code = "my_dataset",
  analysis_results_name   = "t2d_incidence_v1"
)
options[c("datasetId", "analysisResultsName")]

$datasetId
[1] "my_dataset"
$analysisResultsName
[1] "t2d_incidence_v1"

datasetId is the code you passed as source_token_study_code.

Function reference

run_strategus_flow()

Submit a Strategus analysis specification to D2E. D2E starts a run (a "flow run") on the dataset chosen in your options.

Usage

run_strategus_flow(analysisSpecification, executionSettings = NULL, options = list())

Arguments

Argument Type Default Meaning
analysisSpecification analysis specification required The specification you built: cohorts plus modules.
executionSettings NULL Leave as NULL.
options list required The result of create_options().

Value

A list with two elements:

Element Contents
flowrunId The ID of the new run. Keep it: it identifies your run when you ask about it.
status "Successfully created a flow run" 
print(result)

$flowrunId
[1] "923fb707-c76f-45cd-ba05-4a8c8d03a214"
$status
[1] "Successfully created a flow run"

A flow run ID means D2E accepted the run. It does not mean the analysis has finished or succeeded.

Important

  • Every call submits a new run. Running the cell twice submits the study twice.
  • Run All in the notebook runs this cell too. Keep the submit cell last, and run it on purpose.

Examples

result <- run_strategus_flow(
  analysisSpecification = analysisSpecifications,
  executionSettings     = NULL,
  options               = options
)

result$flowrunId   # keep this

Guide

Working with cohorts

Strategus studies run on cohorts defined in ATLAS. rD2E brings those definitions into your notebook.

Find the IDs

  1. In ATLAS, open Cohort Definitions.
  2. Find your cohorts. The ID column is the number to use in R.
  3. Note which cohorts are targets, comparators and outcomes for your study.

Load them

cohortDefinitionSet <- get_cohort_definition_set(
  cohortIds = c(44, 49, 50),
  generateStats = TRUE
)

Use one call for all the cohorts in your study. The result goes into the specification as shared resources:

cohortResources <- createCohortSharedResourceSpecifications(
  cohortDefinitionSet = cohortDefinitionSet)

Check before you build

A quick check catches a wrong or missing ID before you submit:

stopifnot(identical(as.integer(cohortDefinitionSet$cohortId), c(44L, 49L, 50L)))
print(cohortDefinitionSet[, c("cohortId", "cohortName", "generateStats")])

The IDs you use later in module settings (targets, outcomes) must be IDs you loaded here.

Keep generateStats consistent

generateStats in get_cohort_definition_set() should match generateStats in the Cohort Generator module:

cgSpecs <- createCohortGeneratorModuleSpecifications(generateStats = TRUE)

Changed a cohort in ATLAS?

The notebook holds the definition as it was when you loaded it. After editing a cohort in ATLAS, run the get_cohort_definition_set() cell again, and the cells after it.

Create a cohort from the notebook

create_cohort_definition() creates a new cohort definition in ATLAS, for example a copy of an existing one under a new name. TO VERIFY

Guide

Submitting a study

Before you submit

  • [ ] All cells above the submit cell have run without errors
  • [ ] The cohort IDs you loaded match the ones used in your modules
  • [ ] The Cohort Generator module comes before your analysis modules
  • [ ] source_token_study_code names the dataset you mean to run on
  • [ ] analysis_results_name describes this run, so you can tell it apart later
  • [ ] The notebook is saved

Choose the options

options <- create_options(
  source_token_study_code = "my_dataset",
  analysis_results_name   = "t2d_incidence_v1"
)

See create_options() for both arguments.

Submit once

result <- run_strategus_flow(
  analysisSpecification = analysisSpecifications,
  executionSettings     = NULL,
  options               = options
)

Strategus flow run triggered successfully with id: 923fb707-c76f-45cd-ba05-4a8c8d03a214

Each run of this cell submits a new study run. Don't re-run it to "check" something, and be careful with Run All.

What the result means

You see It means
flowrunId D2E created a run with this ID
status: "Successfully created a flow run" D2E accepted the run

It does not mean the analysis finished or succeeded. Runs take time, and progress is tracked by the platform team. To ask about a run, send them the flowrunId.

What happens next

  • Results are reviewed in ATLAS → Studies → Results. That is covered in a separate guide.
  • To change something, edit the cells, re-run them, and submit again. This creates a new run with a new ID.

Troubleshooting

Every message rD2E can show, with what to do.

Signed out

You see What to do
ATLAS shows Your session has expired. Please sign in again. Sign in again. Then run your cells again from the top: the notebook's R session starts fresh.

Long sessions also expire. If rD2E calls start failing after the notebook has been open a long time, sign in again (reload the page if needed) and re-run your cells.
